# DevStack

DevStack is a modern React app that helps developers explore and build their ideal technology stack. It presents a curated list of tools and frameworks, allowing users to select the ones they want in their personal development environment.

## Project Description

This project is designed for developers who want to quickly compare and assemble a tech stack based on their needs. Instead of manually researching tools, users can browse technologies, add them to their custom stack, and keep track of their selected setup visually.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React
- React Toastify
- JSON-based technology data

## Features

1. Explore a curated set of development technologies.
2. Add or remove technologies from a personalized stack.
3. Get instant feedback through toast notifications and a clean, interactive UI.

## Getting Started

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:5173
```

## Project Goal

The main goal of DevStack is to make stack selection simple, visual, and developer-friendly. It is a useful concept for showcasing product thinking, UI design, and front-end development skills.
